# Source-owned immutable research contract v1.1

Frozen base: PR #42 `ef1c53861998188bdd03b9f037dc45573b3c2acb`.

Audit: `ResearchRunner.run` synchronizes requirements then invokes the real strategy executor. Existing `persist_report` and fenced persistence are separate report writers. SQLite `research_results` uses INSERT OR REPLACE; staged promotion also replaces. Strategy fingerprints do not identify input data. PostgreSQL is a control-plane/job store, not a research-result producer. The service worker watches durable job state; this change does not silently wire research into a live service.

`ResearchRunner.run(..., result_store=..., provenance={...})` now freezes actual declared inputs before executing the existing strategy implementation. SQLite backup captures a consistent image per resolved source database; sharded routing resolves once per requirement, and no claim is made of simultaneous snapshots across separate files. Every supported dataset is extracted with inclusive UTC Unix millisecond bounds and validated complete timestamps. All data consumed by the normal StrategyContext interface comes from detached frozen values. Unsupported dataset/custom direct-store interfaces fail closed. Funding is qualified only if it meets the declared timeframe cadence; this conservative rule never manufactures missing events. No AlphaFold or Strategy Engine implementation dependency is introduced.

The immutable owned_runs table records unique UUID attempts. RUNNING survives a crash and cannot be exported. Cancellation/failure aborts the attempt; reruns use new IDs and do not resume unbound checkpoints. Existing complete rows resist UPDATE, DELETE, and REPLACE. The canonical record binds strategy fingerprint/version, empty current engine parameters, producer identity/revision/epoch, source identity and market type, exact dataset windows, retained input_snapshot, model kind/version and execution assumptions (execution, nonnegative fees/slippage), output metrics, completion time, and SHA256 completion_receipt. This receipt is created only after strategy returns successfully and publication authority remains valid. Caller callbacks must be tied to the actual scheduler lease/cancellation source; defaults are appropriate for standalone runs without a distributed lease. As with existing fenced publishing, no distributed atomic transaction across job-state and local SQLite is claimed. Nonempty parameters and checkpoint resume are rejected because current strategy execution lacks a binding adapter.

HTTP outer envelope remains v1.0; immutable records are v1.1. GET /internal/v1/runs uses existing limit<=100 and offset<=10000. GET /internal/v1/runs/{id}/metrics exports the same records under runs, including the retained immutable input artifact. Aggregate artifacts larger than 900000 bytes remain unavailable through this bounded gateway. Query-only SQLite transaction, 100ms SQLite progress deadline, and read-only open ensure no result writes. Legacy health/capabilities continue reporting their unqualified boundary; additive immutable_research_v1_1 capability declares implemented schema support. No socket is started by this module.

API requires both trusted_sources tuples (producer_identity, source_revision, source_identity) and independently admitted trusted_receipts tuples (producer_identity, source_revision, run_id, completion_receipt). Default trust sets are empty. Source declarations and matching hashes alone grant no qualification. The caller must obtain receipt admission out of band from the source owner. In tests this admission is synthetic. No real producer receipt or physical attestation is supplied by this PR. Qualified responses say HISTORICAL, execution_authority=false, freshness=HISTORICAL, physical_attestation=UNVERIFIED. They never assert LIVE or authorize trading. Unknown/missing identity, invalid receipt, corrupt data, incomplete/crash-left attempts and unsupported versions produce UNAVAILABLE with safe reason codes. Listings select only COMPLETE attempts; unfinished attempts remain explicitly UNAVAILABLE when queried by ID. A crash-left attempt never blocks a successful independent rerun from being listed.

Dataset coverage is the exact string COMPLETE; missing_data is an empty list for qualified runs. Dataset datasets lists each dataset/timeframe/count. input_snapshot contains exact canonical rows. Fingerprint hashes {dataset: metadata without fingerprint, rows: input_snapshot}; completion_receipt hashes the whole record excluding itself. SHA256 is integrity, not authenticity.

Grid handoff must accept this v1.1 record through a read-only validator with independent receipt admission. Unified System and Terminan need explicit adapters for this richer schema; their existing synthetic SEALED v1.0 format is separate. Existing clients must not infer execution authority from API availability. Owner admission, physical observations, production integration and commissioning remain external blockers.
