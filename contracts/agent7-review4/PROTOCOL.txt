Identity and projection
raw_sha256 hashes the COMPLETE UNMODIFIED selected legacy artifact bytes,
including whitespace and original numeric tokens. It is not a C3 root, cursor,
source authenticity proof, financial exactness proof, or authority receipt.
The supplied expected digest is independently checked against captured bytes;
its authenticity is the caller's obligation, not established by this model.
Do not replace the retained artifact with reconstructed/rounded JSON.
The reference is a NEW resource, with a NEW schema hash and a NEW C3 byte hash.
It must never reuse a legacy digest as a new root/cursor. This module issues
neither roots nor cursors. One explicitly partial resource per source artifact
is proposed. No hidden row splitting, truncation or stringified-history bypass.
Original artifacts MUST be retrievable through admitted Storage and independently
hash-verified by the consumer BEFORE any real data success/admission. This
package has no Storage client and reports retrieval as REQUIRES_ADMITTED_STORAGE_
AND_INDEPENDENT_HASH_VERIFICATION. It never asserts successful retrieval.
All lineage is CALLER_DECLARED_NOT_AUTHORITY_ACK. Fixture UUIDs and hashes are
synthetic declarations, not registry records or production endpoints.

Research
Source schema meta.ohlcv.research.result.v1. Complete source budget 16777216
bytes; rows 1..2000. One explicit selected row index and OHLCV field. All rows,
levels, units, numeric lexemes and remaining provenance stay in the raw artifact.
No inline rows. projection_complete=false always. Dataset's legacy 64-hex
content identity stays separate from registry_dataset_id UUIDv4.
Six source clock tokens must be exact canonical nonnegative integers <=2^53-1;
transport is canonical decimal STRING, unit UTC_UNIX_MILLISECONDS, scale 1.
calculated_at_ms is the analysis clock, never historical observation time.
Scientific scalar: finite JSON number explicitly decoded as IEEE754 binary64,
then its exact 64 bits encoded as 16 lowercase network-order hex digits.
This preserves decoded binary64 including negative zero; it does NOT claim exact
original decimal rational value. Full original lexeme remains in raw artifact.
Integer scalar lexemes outside +/- (2^53-1) are rejected rather than rounded.
Unit copied exactly from source units.price for open/high/low/close, units.volume
for volume. No rescaling; NO_DECIMAL_RESCALE. This is a scientific observation,
not an executable price, quantity, money, fee, collateral or account value.
The binary64 decoder rejects infinities/NaNs. Financial promotion is forbidden.

Numeric and identifier grammar
See numeric-profile.json and exact schemas. ASCII only in C3 payload. Integers
are decimal strings matching 0|[1-9][0-9]* and bounded explicitly. No plus,
leading zeros, exponents, whitespace, decimal points, booleans or numeric coercion.
u63 <=9223372036854775807; clocks <=9007199254740991. Item counts scale1 ITEM,
byte_count scale1 BYTE; registry_revision/lease_epoch scale1 MONOTONIC_COUNTER.
IDs are lowercase UUIDv4, commits/trees lowercase 40 hex, SHA256 lowercase 64 hex.
A UUID does not attest identity or grant authority. Artifact and registry IDs
are distinct semantic fields even when test fixtures reuse a synthetic UUID.

Bounds and encoding
C3 writer: ordinary plain data only; sorted ASCII keys; printable ASCII strings;
no whitespace/BOM/final newline; quote/backslash escapes only; NO numeric literals.
Resource-specific arrays <=32, object members<=64, container depth<=12, nodes
including object keys<=32768, keys1..128, strings<=16384, total<=2097152 bytes.
These are conjunctive caps, not permission to exceed outer frame/route limits.
Reject holes, extra array keys, nonordinary/proxy/accessor/hidden/symbol inputs;
frozen plain data allowed. Source JSON parsing is separate: UTF8 fatal, no BOM,
duplicate decoded keys rejected, numeric tokens retained, depth<=64, <=250000
nodes, <=8192 entries per source array, <=65536 UTF16 units per source string.
Source clocks use token grammar, preventing integer rounding before checks.
Source data may contain legacy Unicode; it stays only in unchanged raw bytes.
The C3 output cannot silently admit it as a transport label.
