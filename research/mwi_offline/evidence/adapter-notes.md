# Adapter evidence and seam

Owned files: mwi_offline/adapter.py, tests/test_adapter.py. Stdlib-only local synthetic format `mwi.offline.normalized.synthetic.v1`; not a shared contract, source adapter, export or operational admission API. Scope outputs/MWI-OFFLINE-RESEARCH only.

Observed TDD RED: evidence/adapter-red.txt records ModuleNotFoundError for adapter before implementation. GREEN: evidence/adapter-green.txt records tests after implementation. Symlink creation test skips where Windows privilege is absent; hardlink rejection runs separately. No historical data/training, repository import, DB, runtime/provider/export access.

`write_snapshot(directory,bars,source_head,evidence_class='SYNTHETIC')` creates a new directory beneath an already-existing parent; refuses any existing target, historical class, malformed source HEAD, invalid/overlapping/unsorted clocks and bars. Returns external SHA256 of exact manifest bytes. Caller must keep that pin independently; reading the manifest's own hash is not independent trust.

`load_snapshot(directory,expected_manifest_sha256,expected_source_head,allow_synthetic=False)` requires caller pin and exact HEAD, exact manifest/member schema and fixed filenames, bounded reads/nesting/row count, rejects duplicate JSON keys, nonfinite bar numbers, links/reparse ancestors/hardlinks, mutation and traversal. Default denies synthetic. HISTORICAL always blocks: no separately provisioned historical authenticity policy exists. Gaps are preserved rather than filled; each bar must have open_ms < end_ms <= available_ms. Lexicographic (symbol,open_ms) ordering required. Resource cap 10000 bars/10MiB per file, nesting64. Output data directory should be kept private and stable during reads; path checks are not a hostile concurrent-filesystem sandbox or distributed immutable store.

Native Grid v1.1 future seam is read-only conversion of an independently authenticated offline envelope, not invocation of Grid export/readers. Map symbol and OHLCV, event_start_ms→open_ms, exclusive event_end_ms→end_ms, available_at_ms→available_ms; retain all source receipt/provenance and dataset identity separately. Grid raw inclusive minute end must not be substituted for exported exclusive end. Grid record-fingerprint revisions are not Strattester integer revisions. Hashes cannot establish authenticity/completeness. This implementation intentionally has no converter/admission path for native HISTORICAL envelopes; ROOT ownership and authenticity policy remain blockers.
