## Proposed typed read-only Math adapter (design only)

Ownership rule: Strattester orchestrates input selection, experiments/splits/labels, calls Math through an approved typed boundary and records artifacts. Math owns numerical definitions, numerical validation, feature versions and math result lineage. Meta owns its source-domain orderflow/level derivations. No copied generic Math implementation, monkey-patched source loading, direct provider import, arbitrary eval or caller-selected executable path belongs in Strattester.

Suggested request schema mwi.math.features.request.v1 (PROPOSED, NOT EXISTING):

- request_id, requested_mode=RESEARCH_ONLY, execution_authority=false;
- dataset_id, dataset_hash, manifest_hash, source_revision_set, admitted_capability_manifest_hash;
- decision_cutoff_ms, exact source event/availability arrays with units, missingness/quality status and raw/derived/approximated classification;
- operation whitelist of {operation_id,operation_version,parameters,input_refs,output_unit};
- fixed_math_source_head + full trusted implementation/dependency byte manifest; resource_budget;
- optional immutable fit_artifact_id/hash with train_end/label-availability cutoff for learned transforms.

Each operation returns {status:READY|WARMUP|MISSING|UNSUPPORTED|INVALID, output/value/unit, event_end_ms, available_at_ms, support_interval, dependency_ids/hashes, operation_version, parameters_hash, source_head, request_hash, output_hash}. Bundle result also binds dataset ID/hash and all authority false. Missing values remain masks/status, never unmarked zero or synthetic data. Retain mathematicallyVerified=false and source authenticity status where evidence is absent.

First reuse whitelist: trailing differences/rolling volatility, volatility regime, ACF/lagged dependence summary, descriptive spectral-band powers and Markov transition counts on a bounded admitted prefix; scientific v2 rolling mean/lag/derivative/integral and dimension-checked arithmetic. Where current approved source API cannot call the requested Python primitive, return UNSUPPORTED; a Math-owner follow-up supplies allowlisted source-owned worker dispatch. Do not claim a generic callable endpoint exists now.

Clock verification must happen both at read-only admission and owner math boundary: all dependencies available<=decision; source rows contiguous where required; training transforms use only admitted fit prefix; output available=max(actual dependencies). Source event time is not availability. Reject equal lengths with unequal timestamp grids; forbid silent truncation/forward fill. No writing source datasets, registries, ROOT policies, model publication or simulator ledger. Any fit/calibration artifact is a new immutable research artifact, not execution permission.

Preferred transport is the EXISTING authorized Unified/Math composition after ROOT approves the exact source set; local source-owned stdio can be considered only when its executable paths/bytes and resource lease are independently approved. During pending owner acknowledgement, Strattester may prepare/validate request objects and show UNAVAILABLE; it must not start a fake Math endpoint or duplicate transforms to conceal the missing seam.
